サブエージェントの使用ログ (`~/.claude/subagent-usage.log`) と定義ファイル (`~/.claude/agents/*.md`) を分析して、以下のレポートを出力してください。

## 分析手順

1. **使用ログの読み込み**: `~/.claude/subagent-usage.log` を読み込む（存在しない場合はまだログがない旨を伝える）
2. **定義ファイルの一覧取得**: `~/.agents/agents/*.md` からエージェント名を列挙する
3. **以下のレポートを生成する**:

### レポート項目

#### 使用頻度ランキング
エージェント別の呼び出し回数を降順で表示。

#### 未使用エージェント
一度も呼ばれていないエージェントを列挙。削除候補として提案。

#### 最近の使用傾向
直近7日間・30日間それぞれの呼び出し数を集計（データがあれば）。

#### 推奨アクション
- 30日以上呼ばれていないエージェント → 削除候補
- 高頻度で呼ばれているエージェント → 重要、維持推奨
- description が曖昧で誤呼び出しリスクがありそうなもの → 改善候補

## 出力形式

見やすいテーブル形式で出力すること。最後に具体的なアクション提案をまとめる。
