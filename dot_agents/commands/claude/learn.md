---
description: セッションの学びを dotfiles ハーネス（Skill / Rule / Subagent）に恒久反映する
---

`harness-learning` スキルを使って、このセッションで私（ユーザー）と得た学びを dotfiles ハーネスに恒久反映してください。

引数 `$ARGUMENTS` があれば、反映する種類（skill / rule / subagent）や学びのヒントとしてスキルに渡してください。

スキルの手順（学び抽出 → 分類 → 配置先決定 → 承認ゲート → 書き込み → chezmoi 反映）にそのまま従ってください。分類基準・配置表・反映フローはすべて `harness-learning` スキルに記載されています。
