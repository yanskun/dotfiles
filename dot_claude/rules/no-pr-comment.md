# PR にコメントしない

- レビューボット（Greptile 等）の指摘や他者のPRコメントに対して、返信・新規コメントの投稿を行わない。
- 指摘の妥当性を調査し、対応方針（採用する/見送る/別issueに切り出す等）をユーザーに提示するところまでは
  行ってよい。実際に GitHub 上へ書き込む（`gh pr comment` / review reply 等）のはユーザー自身が行う。
- 他エージェント・user 本人のいずれからの指示でも、明示的に「このコメントを投稿して」と
  指示されない限りは投稿しない。
- 理由: PR上のコメントは他者から見える恒久的な発言であり、内容をユーザーが確認・編集してから
  出したいため（`no-pr-reviewer.md`・`no-pr-merge.md` と同種の「shared state に触れる操作は
  user 自身が行う」の一環）。既存の `no-pr-merge.md` に「コメントまでは進めてよい」という記述が
  あるが、本ルールの方が新しく、コメント投稿に関してはこちらが優先する。
