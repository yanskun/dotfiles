# 無断で git worktree を作らない

- 新しい `git worktree add`（や新規ブランチ用の別ディレクトリ切り出し）を、
  ユーザーの承認なしに実行しない。作業は基本的に「今ユーザーがいるディレクトリ
  （既存の worktree）」上で行う。
- worktree を新規作成する必要が本当にある場合（例: 無関係なコミットが混在した
  ブランチから PR 用にクリーンな差分だけを切り出したい、既存ブランチを保護した
  まま並行作業したい等）は、**先に理由を説明してユーザーに確認**してから作成する。
  「〜のため新しい worktree を作りたいですが、よろしいですか？」と一言確認する。
- `superpowers:using-git-worktrees` 等のスキルが「isolated workspace を確保する」
  という手順を含んでいても、その手順が新規 worktree 作成を意味する場合はこの
  ルールが優先し、無断で作成しない。
- 理由: ユーザーは基本的に今いる worktree で完結させたいと考えており、無断で
  別ディレクトリに worktree を増やされると、変更がどこにあるか把握しづらくなる。
